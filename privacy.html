채널 대시보드 개인정보처리방침

시행일 2026년 10월 5일

1. 무엇을 위한 앱인가요

‘채널 대시보드’는 운영자가 자기 유튜브 채널의 성과를 한눈에 보려고 만든 개인용 대시보드입니다. 운영자 본인 계정과, 운영자가 관리하는 채널만 연결합니다.

2. 받는 정보

  • YouTube Analytics API(읽기 전용, yt-analytics.readonly): 영상별 조회수, 참여(유효) 조회수, 평균 시청 비율, 구독자 증가 수
  • YouTube Data API(읽기 전용, youtube.readonly): 연결한 채널의 ID와 이름

이 앱은 채널이나 영상을 바꾸지 못합니다. 댓글·시청자 개인 정보·결제 정보는 받지 않습니다.

3. 쓰는 곳과 보관

  • 받은 숫자는 이 대시보드 화면에 영상별 통계로 보여 주는 데만 씁니다.
  • 로그인 연결 정보(갱신 토큰)는 운영자의 컴퓨터와 저장소의 암호화된 비밀값에만 보관하며, 화면이나 공개 파일에 넣지 않습니다.
  • 받은 정보를 다른 사람이나 회사에 팔거나 넘기지 않으며, 광고에 쓰지 않습니다.

4. 연결 끊기

Google 계정 → 보안 → ‘타사 앱 및 서비스’에서 ‘채널 대시보드’ 접근 권한을 언제든 지울 수 있습니다. 지우면 그 뒤로는 새 숫자를 받지 않습니다.

5. Google API 서비스 사용자 데이터 정책

이 앱이 Google API에서 받은 정보를 쓰고 다른 앱으로 옮기는 방식은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.
